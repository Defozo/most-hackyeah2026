# Materiały MOST

**MOST: ciągłość lokalnych usług**

DEFOZO SOFTWARE HOUSE | Michał Kiełtyka

MOST pokazuje zależności lokalnych usług, oblicza plany przy ograniczonej obsadzie i sprzęcie oraz prowadzi zespół przez wykonanie i test rezultatu. Przygotowana aplikacja przechowuje model, procedury i solver na urządzeniu, a po odzyskaniu połączenia uzgadnia zapisane zmiany.
