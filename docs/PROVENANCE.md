# Pochodzenie prac i danych

MOST powstał jako odpowiedź na zadanie DEFENCE podczas HackYeah 2026. Zespół: **DEFOZO SOFTWARE HOUSE**. Autor zgłaszający: **Michał Kiełtyka**.

Implementacja obejmuje aplikację React PWA, API, model danych, silnik planowania, testy i narzędzia utrzymania. Przy tworzeniu, analizie i poprawianiu kodu, testów, dokumentacji oraz materiałów demonstracyjnych istotnie korzystano z Codex. Odpowiedzialność za projekt pozostaje po stronie autora zgłaszającego.

Model demonstracyjny, osoby, obserwacje i parametry infrastruktury są syntetyczne. Radio i pompa korzystają z symulacji. Test lokalnego rejestru jest rzeczywistym zapisem i odczytem syntetycznego zgłoszenia.

Film i prezentacja wykorzystują zrzuty oraz nagranie aplikacji MOST. Polski lektor to syntetyczny głos ElevenLabs, bez klonowania głosu autora. Podkład pierwszego filmu jest oryginalną kompozycją z syntetyzowanych przebiegów, bez cudzych sampli. Szczegóły zależności i źródeł zawiera [ATTRIBUTIONS.md](../ATTRIBUTIONS.md).
